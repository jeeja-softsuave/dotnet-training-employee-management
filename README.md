# Employee & Department Management — .NET Training

Capstone project for the .NET training programme (Weeks 1–3). Domain: Employee & Department Management.

## Structure

| Project | Purpose |
|---|---|
| `src/EmployeeManagement.App` | Console application (entry point) |
| `src/EmployeeManagement.Core` | Domain models, interfaces, services, LINQ queries |
| `tests/EmployeeManagement.Tests` | xUnit unit tests |

## Prerequisites

- .NET SDK 10.0 (`dotnet --version` should print `10.0.x`)

## Build, run, test

```bash
dotnet restore
dotnet build
dotnet run --project src/EmployeeManagement.App
dotnet test
```
